# ERA AI — Codebase & Folder Structure Reference

## 1. Top-Level Workspace Organization

ERA AI comprises four active repositories coordinated under a unified runtime:

```
D:\
├── era-voice-assistant/        # Primary Frontend, Express Server, Electron Desktop Shell
├── era_agent/                  # Python Local Agent, OS Controls, Outcome & Mission Engines
├── era_bridge/                 # Python Gateway, Local SQLite Semantic Memory & Telemetry
├── era_vision/                 # Python Vision Perception & Rate-Limiting Policy Agent
└── era_backups/                # Rollback snapshots & pre-refactoring state archives
```
